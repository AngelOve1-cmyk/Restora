# Restora

Sistema Inteligente de Gestión para Restaurantes.

## Descripción

Restora es una aplicación web diseñada para facilitar la administración de las operaciones principales de un restaurante.

El sistema permitirá gestionar mesas, reservas, pedidos, inventario, usuarios y visualizar información relevante mediante un dashboard.

## Tecnologías

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Node.js
- Express.js

### Base de datos
- MySQL

### Otras herramientas
- Git
- GitHub
- Chart.js
- Visual Studio Code

## Módulos principales

- Inicio de sesión y usuarios
- Gestión de mesas
- Gestión de reservas
- Gestión de pedidos
- Gestión de inventario
- Dashboard y reportes
- Alertas y recomendaciones

## Estructura del proyecto

- `frontend`: interfaces visibles para el usuario.
- `backend`: lógica y servicios del sistema.
- `database`: estructura y scripts de la base de datos.
- `docs`: documentación técnica del proyecto.
